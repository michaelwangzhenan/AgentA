# 1. 导出用户对话

从 SQLite 按用户名导出全部会话，生成 history/<用户名>_chat.md，便于复盘网警审核等场景下的对话记录。实现见 tools/cli/getchat.py、src/services/getchat_export.py。

## 1.1. getchat

- 参数：用户名（大小写不敏感）
- 范围：该用户全部 session，按 session 创建时间顺序
- 输出：history/<用户名>_chat.md（覆盖写入；history 目录不存在时自动创建）
- 用户不存在：报错退出，不写文件

导出内容与聊天页历史重载时一致：

- 用户消息：展示正文；若含附件序列化，拆成正文与附件名
- 助手消息：工具调用摘要（名称、参数、preview）及最终回答（Markdown 原文）
- 不含 Plan、Thinking、深度研究进度（UI 重载时也不显示）

每条气泡附带时间，取自 messages 表的 timestamp 字段（ISO 本地时间，精确到秒）。

在仓库根目录执行：

```bash
.venv/bin/python tools/cli/getchat.py <用户名>
```

VPS 上路径相同，使用项目虚拟环境下的 Python 即可。

## 1.2. VPS 互传

仓库根目录的 i.ps1 提供与 VPS 之间的单文件 scp。路径均相对仓库根；远程主机 admin@47.96.93.237，远程目录 /home/admin/AgentA（与 i1.1_3_deploy.md 部署一致）。

- getlog：拉取 VPS 上 logs/uvicorn.log 到本地 logs/vps/
- scpto <本地相对路径> <远程相对路径>：上传到 VPS
- scpfrom <远程相对路径> <本地相对路径>：从 VPS 下载

scpto 要求本地文件已存在；远程父目录不存在时会自动创建。scpfrom 会创建本地缺失的父目录。

```powershell
.\i.ps1 scpto tools/cli/getchat.py tools/cli/getchat.py
.\i.ps1 scpfrom history/admin123_chat.md docs/chat-admin123.md
```
