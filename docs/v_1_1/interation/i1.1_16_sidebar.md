# 背景

桌面端主内容区横向空间偏紧。左侧导航栏默认 256px 宽，可拖拽到 150–480px，目前始终展开。用户希望能像 Claude 那样，用顶部按钮或快捷键把侧栏收成窄图标条，给聊天、看板、数据库等主区腾出宽度。

本迭代只做「整栏收起 / 展开」。与 i1.1_15_mobile.md 的手机适配可以分开做；收起态对窄屏也有帮助，但不依赖那边的方案。

# 需求

侧栏增加收起按钮，在展开态与图标条收起态之间切换；偏好写入 localStorage，刷新后保持。

## 需求分析

### 现状

侧栏由 frontend/src/components/sidebar/Sidebar.tsx 实现，在 AppLayout 里与主内容区水平并排，目前没有整栏收起。

已有能力：

- 视图导航：聊天、知识库、记忆、Rules、Skills、MCP、学而时习、用量/质量看板、数据库、备份等
- Recents 会话列表（区段可折叠，状态存 agenta:sidebar:recentsCollapsed）
- 右缘拖拽调宽（150–480px，默认 256px，状态存 agenta:sidebar:width）
- 底部用户菜单、主题切换

还缺：

- 整栏收起 / 展开
- 收起后的图标条模式
- 收起相关的键盘快捷键
- 主内容区在收起后的展开按钮（收起条顶部同一按钮可承担，不必另做）

参考 Claude 网页版：

- 展开态：侧栏顶部右侧有「收起侧栏」按钮，悬停提示含快捷键 Ctrl+.
- 收起态：侧栏缩成约 48px 竖条，只留图标；顶部同一按钮可再展开；新建、主导航、底部头像等以图标呈现，文字与 Recents 列表隐藏。

### 目标

用户可以随时收起侧栏以扩大主内容区，并通过图标条完成常用导航。收起偏好跨会话、跨刷新保持；再次展开时恢复用户上次拖拽的宽度（与 agenta:sidebar:width 分开存）。

### 交互规格

#### 两种形态

| 形态 | 宽度 | 可见内容 |
| --- | --- | --- |
| 展开（默认） | 沿用现有拖拽宽度，默认 256px | 与现网一致：新建会话按钮、带文字的导航项、Recents、用户区文字 + 主题切换 |
| 收起 | 固定窄宽（建议 48px，实现时可微调） | 顶部收起/展开按钮、新建（仅图标）、各视图导航（仅图标）、底部用户头像（仅图标）、主题切换（仅图标） |

收起态不显示 Recents 列表与区段标题；要浏览或切换历史会话，须先展开侧栏。导航图标悬停显示 tooltip（视图名称），与 Claude 一致。

#### 收起 / 展开入口

1. 侧栏顶部：收起按钮。展开态放在顶栏右侧（与新建按钮同一行，或紧邻导航区上方）；收起态放在图标条顶部，图标语义为「展开侧栏」。
2. 键盘：Ctrl+.（Mac 为 Cmd+.）全局切换收起态；不与现有 Ctrl+/ 聚焦输入框冲突。
3. 收起态下主内容区可不额外放按钮，顶部图标条上的按钮即可展开。

#### 与现有能力的关系

- 收起时：隐藏右缘拖拽条，不按 agenta:sidebar:width 展示像素宽度，但不清除已存宽度；展开时读回上次宽度。
- Recents 区段折叠（agenta:sidebar:recentsCollapsed）与整栏收起无关；展开后侧栏后，Recents 折叠状态照旧。
- 侧栏收起态不进 URL，与 i1.1_11_url_whole.md 对过程态的约定一致。

#### 无障碍

收起/展开按钮提供 aria-label（如「收起侧栏」「展开侧栏」）与 aria-expanded。图标条内导航按钮保留可聚焦与 tooltip，满足键盘与读屏的基本使用。

### 本期范围

1. 整栏收起 / 展开状态与 UI（展开态 + 图标条收起态）。
2. 顶部切换按钮（lucide PanelLeftClose / PanelLeft 或等价图标）。
3. 快捷键 Ctrl+. / Cmd+.。
4. localStorage 持久化（建议 key：agenta:sidebar:collapsed，值 0/1）。
5. 收起态下图标导航、新建会话、用户菜单、主题切换可用（用户菜单可仍为下拉，从头像图标触发）。

### 已确认决策

需求讨论时定了四项：

| 决策 | 选择 |
| --- | --- |
| 收起态宽度 | 48px |
| 收起态 Recents | 完全隐藏 |
| 窄屏默认 | 保持展开，与桌面一致；响应式策略留给 i1.1_15 |
| 展开动画 | 宽度过渡约 200ms |

### 不在本期

- 手机端抽屉式侧栏、遮罩层（留给 i1.1_15 或后续）。
- 收起态下 Recents 的浮层 / 飞出面板的完整会话管理。
- 侧栏收起态写入 URL 或分享链接。
- 替换现有 shadcn Sidebar 组件库（继续自定义 Sidebar.tsx）。

### 与 i1.1_15 的关系

i1.1_15 讨论手机显示不全；本迭代不依赖其方案。收起图标条能减少横向占用，对窄屏有一点帮助，但不替代响应式布局或抽屉导航。两文档可并行推进；小屏是否自动收起等合并策略，留到 i1.1_15 定稿时再对齐。

### 验收标准

1. 展开态点击顶部按钮或按 Ctrl+.，侧栏变为窄图标条，主内容区变宽。
2. 收起态再次点击顶部按钮或按 Ctrl+.，侧栏恢复展开，宽度为收起前保存的拖拽宽度。
3. 刷新页面后，收起/展开状态与展开宽度分别保持。
4. 收起态下可通过图标切换各主视图、新建会话、打开用户菜单与主题切换。
5. 收起态不显示 Recents；展开后 Recents 行为与现网一致。
6. 收起态不显示宽度拖拽条；展开态拖拽与双击重置仍可用。
7. 收起态导航图标 tooltip 可见；按钮具备基本 aria 属性。
