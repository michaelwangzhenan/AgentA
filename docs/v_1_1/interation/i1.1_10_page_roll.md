# Golden 管理

## 增加翻页
问题：UI 质量看板 - Golden 管理页面显示不全，没有导航栏，不能翻页
需求：增加导航栏，可翻页。具体实现参考 数据库页面得做法。

### 设计

Golden 管理列表超过单页上限时只能看到第一页数据。在 GoldenManager 接好后端已有的 limit/offset 分页，并加上与数据库页一致的分页导航栏。

### 范围

只改 frontend/src/components/eval/GoldenManager.tsx。后端 eval/golden、getGolden、GoldenList 已有 total/limit/offset，不动。

### 交互

- 表格上方加分页栏：上一页、条数范围、下一页、页码、跳至、每页条数（10 / 20 / 50 / 100，默认 10）
- 样式与行为对齐 DatabaseView 的 SqliteRows + Pager（组件内联复制，不抽公共）
- 改状态 / 来源 / 文档筛选 / 来源文件搜索时，offset 归零回第一页
- 翻页或刷新后清空当前页勾选（与现有一致）

### 边界

删除后若当前页已无数据，按新 total 收紧 offset，避免空白页。

## 增加过滤

### 需求

原先只支持按来源文件筛选。增加按「问题」子串筛选，工具栏不新增控件。

### 设计

- 现有来源下拉增加「问题」选项（value=query）
- 选「问题」时：旁侧输入框 placeholder 改为「按问题筛选…」，请求带 query_contains
- 选全部来源 / AI 生成 / 手工时：行为不变，输入框筛 source_contains；下拉值仍映射 source
- 切换下拉选项时清空输入并回第一页
- 后端 golden_store / eval/golden / getGolden 增加 query_contains（LIKE 子串，对齐 source_contains）
