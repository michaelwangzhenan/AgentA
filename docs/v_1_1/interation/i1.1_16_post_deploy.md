# 1. 底部 log 美化

## 1.1. 背景 
ICP备案和公安备案都已经通过，并且把连接和logo 加到了页面底部。
但是现在看起来很low, 需要进行优化，使其看起来高端大气

## 1.2. 需求

### 1.2.1. 目标

全站底部备案栏视觉降噪：信息合规完整，样式参考百度主页底部细条（单行、极薄、半透明深色底、浅色小字），存在感低但不影响审核可读性。

### 1.2.2. 展示范围

登录页与主界面（聊天区等）均展示同一贴底底栏，全站一致。

### 1.2.3. 内容

从左到右单行排列，项之间用空格或「·」分隔，不用竖线。

产品链接（页面未就绪，点击 toast「页面建设中」）：

- 关于 AgentA
- 使用须知
- 帮助中心
- 隐私政策
- 联系我们

合规信息（硬性要求，链接目标不可删改）：

- 浙ICP备2026055936号-1，链至 beian.miit.gov.cn
- 公安备案官方图标 + 浙公网安备33010502013300号，链至 beian.mps.gov.cn 查询页

### 1.2.4. 布局

贴底浮层：fixed bottom-0，横跨页面宽度，浮在内容上方。主内容区预留底部 padding（约 pb-8），避免最后一条消息或表单被遮挡。底栏 z-index 低于弹窗，高于普通内容。

### 1.2.5. 样式

- 背景：半透明深色 scrim + backdrop-blur；底栏与页面主题解耦，不跟 warm/amber 皮肤变色
- 浅色主题：bg-black/50 text-white/85
- 深色主题：dark:bg-black/70，并加 dark:border-t dark:border-white/10 划出顶边，避免条带与深底融在一起
- 文字：text-xs，hover 略提亮并下划线
- 高度：约 28–32px，单行优先，窄屏允许换行
- 公安图标约 14px，与文字垂直居中；图标 alt 写「公安备案图标」；深色 scrim 下实测可读，必要时微调亮度，不换官方图

### 1.2.6. 实现约定

产品链接与备案链接分两类处理：备案链外部跳转；产品链暂无目标时统一 toast，后续有真实页面时只改链接配置，不必动组件结构。

### 1.2.7. 主题切换

底栏采用固定 scrim + 浅色字，不走 background / muted-foreground 等 token。切主题时交互不受影响，但深色皮肤下条带边界可能变淡，需靠更高透明度与顶边线兜底。

浅色（light、warm-light、amber-light）：深 scrim 叠浅底，对比充足，接近百度主页效果。

深色（dark、warm-dark、amber-dark）：页面底色已深，scrim 与背景色差小，白字仍须可读，条带靠 blur 与顶边线保持可辨。暖色深色皮肤的 scrim 保持中性黑，不跟琥珀/咖啡色调，属刻意选择（合规条中性呈现）。

跟随系统（system）：底栏样式不变，背后页面随 OS 深浅切换，对比度随内容背景变化；与手动切主题行为一致。

验收时须在 6 种有效主题（light、dark、warm-light、warm-dark、amber-light、amber-dark）下各看一遍：字可读、条带可辨、公安图标清晰、toast 正常。

### 1.2.8. 验收

- 登录页、主界面底部均为同一贴底细条，不抢主内容
- 备案链接可点；滚动到底时内容不被底栏遮住
- 产品链接点击弹出「页面建设中」
- 主题切换见 1.2.7

### 1.2.9. 参考

综合百度地图底部（工具页浅细条、低对比）与百度主页底部（半透明叠底、单行密排、产品链 + 合规文案）。本需求取主页风贴底浮层，全站统一应用。
