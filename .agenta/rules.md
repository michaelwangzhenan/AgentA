## 回答风格
- 用中文回答；代码、命令、文件路径、英文术语保持原文。
- **先给结论或核心答案**，再展开推理；不要把推理过程堆在前面。
- 涉及多步流程 / 多方案对比时**优先用 Markdown 表格**，少用纯 bullet 堆砌。


## 代码示例
- 代码示例必须**可直接复制运行**：带必要的 `import` 和最小可工作配置，不要写 `# ... your code here` 这种占位。
- 引用本仓库代码请用 `path/to/file.py:line` 形式，便于跳转。
