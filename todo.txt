3. 重排序（Reranking）=> Done
  目标： 在向量检索结果上加 Cross-Encoder 二次排序，提升精度
  背景:
    当前 retriever.py 采用两个 Bi-Encoder（SentenceTransformer）+ round-robin 合并：
      · all-MiniLM-L6-v2     → 英文向量化入库 / 召回 kb_en collection
      · BAAI/bge-small-zh    → 中文向量化入库 / 召回 kb_zh collection
    Bi-Encoder 速度快但精度有限——它将 query 和 document 各自单独编码，
    无法捕捉两者之间的细粒度语义交互。

    Reranking 引入第三个模型 Cross-Encoder（ms-marco-MiniLM-L-6-v2）作为二阶段精排：
      · 三个模型职责不同，互不替代，同时工作：
          阶段一（召回）：两个 Bi-Encoder 各自查询 → round-robin 合并取 top_k×3 候选
          阶段二（精排）：Cross-Encoder 对候选逐对打分 → 降序重排 → 截取最终 top_k 条
      · RERANKER_ENABLED=false 时跳过阶段二，两个 Bi-Encoder 行为完全不变（向后兼容）

    三个模型对比：
      模型                       职责          输入          特点
      all-MiniLM-L6-v2          英文召回       单个文本      速度快，支持批量入库
      BAAI/bge-small-zh         中文召回       单个文本      速度快，支持批量入库
      ms-marco-MiniLM-L-6-v2    精排打分       (query, doc)  精度高，不可用于入库

5. 支持 Skills => Done
  目标： 
    符合 skills 规范， 参考: https://agentskills.io/specification
    如何支持 skills 参考: https://agentskills.io/client-implementation/adding-skills-support
    本项目 skills 目录： advanced/skills/
  实施计划：
    Step1 发现(Discover)
      新建 src/cli/skill_loader.py
      扫描 advanced/skills/**/SKILL.md（最大深度4）；按 name 去重（同名取项目级优先）

    Step2 解析(Parse)
      提取 YAML frontmatter → name, description；body = frontmatter 之后的 Markdown
      宽容模式：缺 description → 跳过并警告；其余字段问题 → 警告但继续加载

    Step3 披露(Disclose)
      若有 skill，在 SYSTEM_PROMPT 末尾追加 catalog 块：
        <available_skills>
          <skill><name>…</name><description>…</description><location>…</location></skill>
          …
        </available_skills>
        + 指令：当任务匹配某 skill，先调用 load_skill(name) 读取完整指令再执行
      无 skill 时完全省略该块

    Step4 激活(Activate)
      模型驱动：注册工具 load_skill(name) → 返回 <skill_content> 包裹的 body
        name 限定为已发现的 skill 名（enum），防止幻觉
      用户显式：CLI 识别 /skill-name [问题]，直接注入 body 到 system，复用 prompt_loader 的模式
      tab_complete.py 中加入 /skill-name 补全

    Step5 上下文管理
      load_skill 返回的 tool result 标记 protected=True，截断历史时跳过
      session 内去重：同一 skill 已激活则不重复注入

    文件改动清单
      新建 src/cli/skill_loader.py  （发现+解析）
      改   src/agent/tools.py       （注册 load_skill 工具）
      改   src/agent/agent.py       （SYSTEM_PROMPT 拼接 catalog；protected 保护逻辑）
      改   src/cli/tab_complete.py  （加入 skill 命令补全）
      改   main.py                  （启动时调用 skill_loader，传入 agent）
