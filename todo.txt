2. 知识库未命中时自动联网搜索
  目标： 当 `search_knowledge` 返回空或相似度过低时，通过指令（对话）触发 LLM 自行搜索，
    并提示 LLM 优先在国内网站查找信息，而非直接返回"暂无内容"。
  
  详细实施计划：
    【根本原因重新定位】
      经验证明：LLM 本身已具备自主决策访问哪些网页的能力（通过 fetch_url 工具）。
      真正的问题是：SYSTEM_PROMPT 第3条用"可调用"语气太弱，LLM 知识库没命中时倾向于
      直接放弃，而不是主动去搜。且 LLM 自选 URL 时偏向 Google/Reuters 等国外网站，在无代理环境下经常超时失败。
      方案：仅改 System Prompt + fetch_url description，无需新增工具。

    【Agent 层 — agent/agent.py SYSTEM_PROMPT】
      修改工具调用策略第3条，将"可调用"改为"必须"，并明确国内网站优先级：
        旧：若知识库无相关内容，可调用 fetch_url 抓取指定网页获取补充信息。
        新：若 search_knowledge 返回"知识库为空"或内容与问题明显无关，
            **必须主动调用 fetch_url 进行网络搜索**，不允许直接回复"暂无内容"。
            选择 URL 时优先访问国内可达网站，例如：
              · 新闻资讯：xinhuanet.com、people.com.cn、百度新闻(news.baidu.com)
              · 技术问题：segmentfault.com、csdn.net、zhihu.com
              · 通用搜索：baidu.com、so.com（360搜索）
            若国内网站无法提供有效信息，再尝试访问国外网站。

    【工具层 — agent/tools.py fetch_url description】
      在 fetch_url 的 description 中补充国内网站引导说明：
        新增：「知识库无内容时，优先抓取国内可访问网站，
        如 xinhuanet.com、people.com.cn、baidu.com、zhihu.com、segmentfault.com 等」

    【测试】
      - 单元测试：SYSTEM_PROMPT 包含"必须"强制搜索策略和国内网站示例
      - 单元测试：fetch_url description 包含国内网站引导说明
      - 集成测试（integration marker）：验证知识库无命中时 Agent 主动调用 fetch_url
