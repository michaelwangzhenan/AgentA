# 关于 AgentA

AgentA 是一款面向学习与研究的**个人 AI 学习助手**：把私有资料放进知识库，用对话检索、规划学习路径，并支持出题与间隔复习。

## 核心能力

- **知识库与溯源**：上传文档后可用混合检索找到出处，回答附带引用标注
- **学习闭环**：学习计划、测验生成与间隔复习（SRS），覆盖从资料到巩固的全流程
- **技能扩展**：通过 Skills 与 MCP 接入外部工具，按需扩展 Agent 能力
- **多模型可切换**：支持多家国内外模型与本地推理，配置即可切换
- **私有部署**：数据保存在你自己的服务器或本机，适合对资料隐私有要求的场景

## 开源与自托管

AgentA 以开源项目形式发布，可自行部署、阅读源码与参与改进。项目地址见 [GitHub 仓库](https://github.com/michaelwangzhenan/AgentA)。

## 适合谁

- 需要整理论文、笔记、课程资料的研究者与学生
- 希望用 AI 辅助学习规划与自测，又希望数据留在本地的个人用户
- 对学习型 Agent、RAG 与工具编排技术感兴趣的开发者（可作为参考实现）
