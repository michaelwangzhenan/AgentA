# 隐私政策

**生效日期：2026 年 7 月 21 日**

本政策说明本 AgentA 实例（以下简称「本站」或「本服务」）如何处理与你相关的信息。AgentA 通常以**自托管**方式部署：数据主要保存在运行该实例的服务器或本机上，由站点管理员（部署者）负责运维，而非集中式多租户 SaaS。

## 1. 适用范围

本政策适用于你通过本站 Web 界面、API 或相关功能使用 AgentA 时产生的信息处理活动。若你通过第三方链接离开本站，适用该第三方的政策。

## 2. 我们收集的信息

根据功能使用情况，本站可能处理以下信息：

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 账号信息 | 用户名、密码哈希、角色 | 用于登录与权限控制 |
| 会话与对话 | 聊天记录、会话标题 | 保存在本站数据库，供你继续对话 |
| 知识库资料 | 上传的文档、分块与索引 | 用于检索与回答溯源 |
| 用户记忆与 Rules | 长期偏好、自定义规则 | 用于个性化 Agent 行为 |
| 用量与日志 | 模型调用统计、错误日志 | 用于运维、排错与用量看板 |
| 技术信息 | IP、浏览器类型、Cookie | 用于会话维持与安全 |

我们不会出售你的个人信息。密码以哈希形式存储，不以明文保存。

## 3. 使用目的

- 提供登录、对话、知识库检索等核心功能
- 区分角色权限，防止未授权访问或写入
- 统计用量、改进稳定性、排查故障
- 履行法律法规要求或应对安全事件

## 4. 存储与本地化

- 数据默认存储在**部署本实例的机器**上（如 SQLite、Chroma 索引、上传文件目录等），具体路径由管理员配置。
- 保留期限取决于管理员策略：备份、日志轮转与账号删除由部署者执行。
- 若管理员将实例部署在境外服务器，数据可能位于该司法管辖区。

## 5. Cookie 与会话

本站使用会话 Cookie（或同等机制）维持登录状态。关闭浏览器或登出后会话失效。请勿在公共设备上保持登录。

## 6. 第三方服务

为提供 AI 能力，本站可能将**你输入的内容片段**发送至你所配置的 LLM 服务商（如云端 API 或本地 Ollama）。此外，启用 MCP 或外部工具时，相关请求可能到达第三方端点。请管理员在配置 API 密钥与 MCP 时评估供应商政策。

我们不会将你的知识库全文主动提供给无关第三方；但发往模型 API 的提示词与检索片段受该服务商条款约束。

## 7. 你的权利

在适用法律允许范围内，你可以：

- 查询本站保存的与你账号相关的信息（通过管理员协助）
- 请求更正账号资料或重置密码
- 请求删除账号及关联数据（由管理员在备份策略允许时执行）

行使权利请 [联系我们](/contact)。自托管场景下，**站点管理员**是主要的数据控制方。

## 8. 安全

我们采取合理措施保护数据（访问控制、HTTPS 传输、权限分级等），但无法保证绝对安全。请勿上传高度敏感且未加密的资料，除非你已经评估过风险。

## 9. 政策更新

我们可能修订本政策。更新版本将发布于此页并更新生效日期。重大变更时，我们可能通过站内提示告知。

## 10. 联系我们

如对本政策有疑问，请通过 [联系我们](/contact) 与站点管理员沟通。
