# 使用须知

使用本网站及 AgentA 服务前，请阅读以下条款。继续使用即表示你理解并同意本须知。

## 1. 账号与访问

- 本站**不开放自助注册**。体验请使用登录页的「立即体验」，或 [联系我们](/contact) 申请账号。
- 账号由站点管理员创建与分配，请勿将密码转告他人。
- 体验账号仅供浏览与评估产品，完整写入能力需申请提升权限。

## 2. 角色与权限

| 角色 | 说明 |
| --- | --- |
| readonly | 可浏览各功能界面，不能修改数据或触发写入类操作 |
| user | 可使用聊天、记忆、Rules、学而时习等核心模块的写入能力 |
| admin | 在 user 基础上，可使用知识库入库、Skills、系统配置、备份等高级功能 |
| 主账号 | 在 admin 之上，额外拥有用户管理（新建账号、调整角色） |

具体模块权限以线上界面与后端校验为准。readonly 账号的聊天区可能展示样例会话，不代表你的私人数据。

## 3. 内容与合规

- 你上传到知识库或输入到对话中的内容，须为你有权使用的资料，不得包含违法、侵权、恶意或滥用性内容。
- 不得尝试绕过权限、攻击系统、批量爬取或干扰他人使用。
- 模型生成的回答仅供参考，不构成专业意见；重要决策请自行核实原始资料。

## 4. 服务性质

- 本实例主要用于产品演示或个人/机构自用部署，**不承诺**特定可用性、响应时间或结果准确性（无 SLA）。
- 管理员可能因维护、升级或安全原因暂停服务，并尽可能提前说明。

## 5. 条款变更

我们可能更新本须知，更新后的版本将发布于此页面并注明生效日期。若变更重大，将通过站内提示等方式告知。

如有疑问，请 [联系我们](/contact)。
