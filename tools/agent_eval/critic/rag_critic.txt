判定标准（每条独立打分，给 0 或 5）：

- **score = 5（相关）**：片段直接覆盖问题主题，包含可用于回答的事实 / 定义 / 例子 / 步骤
  - 部分相关（提到主题但深度较浅 / 边缘相关）→ 默认 5（宁松勿严，避免误删）
- **score = 0（不相关）**：片段与问题无明显语义关联，或仅出现关键词但语境完全跑偏
  - 例：问题是"如何在 Python 用 asyncio"，片段讲"JavaScript 的 async/await" → 给 0
  - 例：问题是"什么是间隔重复"，片段讲"金融市场重复交易" → 给 0

注意事项：

- **每条片段独立判断**，不因前几条已是 5/0 而盲从（避免 list bias）
- 关键词重叠 ≠ 语义相关；判断标准是"用这条片段能否帮回答用户问题"
- 如果不确定，倾向给 5（用户主权 — 让 LLM 在更多上下文里自己判断；critic 只剔除明显跑偏）
